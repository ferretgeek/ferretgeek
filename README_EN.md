<details>
<summary><b>New to GitHub? Start here</b></summary>

- **Try a browser tool:** Download and extract the complete email alias generator source, then open `index.html`. It generates addresses, not new mailboxes; check that your email provider supports tagged addresses.
- **Run a desktop tool:** Both Codex quota tools offer Windows release packages. Follow their download links or open **Releases**, then check the account and runtime requirements.
- **Install an Obsidian plugin:** Follow the AI writer's installation guide and configure your model service.
- **Run other tools:** Some projects need a runtime such as Python; others require building from source or a server deployment. The LAN video player and prompt journal currently require building from source. Each project README explains its requirements.

The **README** is the user guide, **Releases** contains published versions, and **Issues** is where you can report problems. Screenshots and setup instructions live on each project's page.

</details>
